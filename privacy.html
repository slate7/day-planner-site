Privacy policy

day-planner · last updated 9 October 2026

day-planner is a personal scheduling tool with a single user: its author. It is not offered as a service to anyone else, and it collects no data from visitors to this page.

What the application accesses

When its owner authorizes it, day-planner uses the Google Calendar API and the Google Tasks API on that one account. Specifically it reads calendar events in order to identify free time, creates and updates events on a single dedicated calendar named Planned (AI), and creates and updates tasks in a single list named Coursework.

It does not read Gmail, Drive, contacts, or location, and it requests no scopes beyond calendar and tasks access.

Where the data goes

Calendar and task data is processed in memory during a scheduled run and is not stored in any database or sent to any analytics service. The only data written to disk is a small state file recording assignment titles, due dates, time estimates, and how many minutes have been scheduled against each. That file lives in the owner's own private source repository.

Assignment titles, due dates, and a summary of the day's existing commitments are sent to the Anthropic API so that a language model can classify entries and propose placements. That data is subject to Anthropic's privacy policy. No credentials are ever sent.

Sharing

Nothing is sold, rented, or shared with third parties. The only external services involved are Google (whose data it is) and Anthropic (as described above).

Limited Use

day-planner's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Retention and removal

Access can be revoked at any time at myaccount.google.com/permissions, which immediately and permanently stops all access. The stored state file can be deleted outright; doing so loses only scheduling history.
